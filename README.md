# Maryum Gohar — Portfolio Site

A single-page portfolio website for a Graphic Designer & Social Media Manager.

## Contents

```
maryum-gohar-portfolio/
├── index.html      # the entire site (HTML + inline CSS + inline JS)
└── assets/         # 30 project images referenced by index.html
```

## How to view

Just open `index.html` in any web browser — double-click it, or drag it into a
browser window. Everything is self-contained; no build step or server needed.

## How to publish

Upload the whole folder (keeping `index.html` and the `assets/` folder together)
to any static host — Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any
regular web server.

## Notes

- Fonts (Bricolage Grotesque, Fraunces, Hanken Grotesk) load from Google Fonts,
  so the typefaces need an internet connection to display exactly as designed.
  The layout and content work offline regardless.
- Light and dark themes are both included; there's a toggle in the top-right of
  the site, and it also follows your system preference by default.
